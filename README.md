# not-yet.app

Website for the app **Not Yet**, hosted on GitHub Pages. Static, no framework, no build on the server: every file is served exactly as it is here. The language versions are generated locally by a small Python script (`tools/build-i18n.py`, see "Languages"); the output is committed as well.

It is based on style 02 "Apple Product Page" (app repo: `docs/design/mockups/website-styles/style-02.html`). The hero follows variant A of the decision page `docs/design/mockups/website-hero.html` (fan of five phones, "A day" sentence, hint of apricot, watch on desktop only, fan opens on load, slim nav, platform line below the CTA, claim in Fraunces). Requirements: `docs/entscheidungen.md` P82 (positioning), P83 (never "Free"/"kostenlos" anywhere), P79 (apricot, never white on apricot), P73 (house voice, `docs/stimme.md`).

### Tech in brief

- **Light is the default.** The toggle at the top right sets `data-theme="dark"` on `<html>` and remembers the choice (`localStorage`, key `notyet-theme`). Without JavaScript the page stays light and the toggle is hidden.
- **Screens in both themes:** every spot has two `<img>` (`.only-light`/`.only-dark`) with `srcset` 360/720 and `loading="lazy"`. The hidden image is never loaded.
- **The source is templates + texts** in `tools/i18n/` (section "Languages"). The HTML files in the repo are generated; changes made there are lost on the next build. Names from the app (Focus lock, Bedtime lock, Adult sites, Wheel, Sidequest, Run …) stay in English in every language because the app is in English; every non-EN page says so unobtrusively (FAQ and a line below the CTA).
- **Motion:** everything is in `home.js`/`home.css`. The hero fan opens once on load (pure CSS, `@property --s`), then the watch fades in. With "Reduce motion" (`prefers-reduced-motion`) everything is static and immediately visible; the rotation then does not play automatically.
- **Nav:** slim, no line. On the home page it carries the hero's apricot ground until the hero has scrolled away (`.nav.past`, `home.js`).
- **CSP without `'unsafe-inline'`:** this also means no `style="…"` attributes in the HTML. Set per-element values via classes or `:nth-child` in CSS.
- **No cookies, no third parties.** The only exception to `'self'`: the self-hosted Umami instance at `https://a.not-yet.app` (visit counting, section "Umami"). CSP via `<meta>` (Pages cannot set headers): `script-src`/`connect-src` `'self' https://a.not-yet.app`, otherwise `'self'`, `object-src 'none'`. No inline script, except the JSON-LD data (not executed). The **app** itself has no tracking; texts always keep the two apart ("no tracking in the app").
- **Fonts:** Apple devices use SF Pro (system). Others load `assets/fonts/inter-var-latin.woff2` (48 KB) from the site's own domain. The claim in the hero is Fraunces Soft 500 (`assets/fonts/fraunces-soft-latin.woff2`, 38 KB, Latin-1, same as in the app), home page only, via `preload`.
- In `404.html` and `t/index.html` use only absolute paths (`/assets/…`), because the 404 page is served under any path.

## Languages

EN (`/`), DE, ES, FR, IT, PT (Brazil), JA, KO (`/<code>/`). All pages share the same structure; only the texts differ.

```
python3 tools/build-i18n.py         # all pages, 404.html, t/index.html, sitemap.xml
python3 tools/build-i18n.py --og    # also og.png and og-<code>.png (needs Google Chrome)
```

- **Changing text:** change the key in `tools/i18n/en.json` **and in all other languages** (`de.json`, `es.json` …), then build. The script aborts if a language is missing a key or has an extra one, and flags straight quotes `"` in the text (they break attributes; use typographic ones).
- **Changing structure** (section, image, class): in `tools/i18n/templates/*.html`. `{{home.hero_sub}}` pulls text from the language file (may contain inline HTML), `{{@…}}` is computed by the script itself (URLs, hreflang, language menu, `{{@testflight}}` = public TestFlight link from `TESTFLIGHT` in the script, `mailto:` links, Umami attributes), `<!--if ns.key-->…<!--/if-->` appears only if the text is not empty (e.g. the "app is in English" note, empty in `en.json`), `<!--each-lang-->` repeats a block per language (404 and tag page).
- **New language:** create `tools/i18n/<code>.json` (copy of `en.json`, fill in `_meta`), add the code to `LANGS` in `build-i18n.py` and to `assets/js/lang-redirect.js`, build. Translate as transcreation in the house voice (`docs/stimme.md`), followed by a review by native speakers.
- **Language detection:** GitHub Pages cannot evaluate `Accept-Language`. So only `/` loads `assets/js/lang-redirect.js` in its `<head>`: if the visitor has not picked a language yet (`localStorage` `notyet-lang`), it goes to the first supported language from `navigator.languages` (`location.replace`, the anchor is kept). If English comes before every other supported language, it stays at `/`. Language pages never redirect (no loop), bots/Lighthouse are never redirected, without JS `/` stays English. After a pick in the language menu, `/` never redirects again (not even to the chosen language). Search engines find the languages via `hreflang` (all languages + `x-default` = EN) in the `<head>` and in the sitemap.
- **Language menu:** `<details class="lang">` in the nav of every page, works without JS; each entry links to the same page in the other language. On the 404/tag page the entries lead to the respective home page.
- **Japanese/Korean:** system fonts (Hiragino / Apple SD Gothic Neo, otherwise Yu Gothic / Malgun Gothic / Noto), no negative tracking, line breaks with `word-break: auto-phrase` (ja) or `keep-all` (ko). The claim uses Fraunces for Latin script only.

## Umami (visit counting)

Same as for kescher.app: a self-hosted, cookieless Umami instance, for the website only; the app sends nothing.

1. The Umami website `not-yet.app` exists; its ID is set as `WEBSITE_ID` in `assets/a.js`.
2. DNS: point `a.not-yet.app` at the Umami server (Cloudflare, record for `a`), with a valid HTTPS certificate. The server must serve `https://a.not-yet.app/s.js` and `/api/send`.
3. If the host changes, update it in two places: `TRACKER_ORIGIN` in `assets/a.js` and the CSP in all templates (`tools/i18n/templates/*.html`), then build.
4. Privacy: the hoster and location of the Umami server are named in the privacy texts (all `tools/i18n/*.json`).

What is counted: page views (without query and anchor) and clicks with `data-umami-event`: `testflight-invite` (click on the public TestFlight link, with `lang` and `place`: nav, hero, cta, faq, support, tag), `language-switch` (`from`, `to`), `theme-toggle`. On `/t/<id>`, `a.js` counts only `/t/`, never the tag ID. Opt-out: switch on the privacy page or `localStorage.setItem('umami.disabled','1')`; the script is then not loaded at all.

Check after entering the ID: open the page; in DevTools (Network) `s.js` must load from `a.not-yet.app`, and clicking "Join on TestFlight" must send a `POST /api/send`; no CSP errors in the console; the visit shows up in Umami.

## Deploy to GitHub Pages

Repo: **STACK25/not-yet.app** (public), branch `main`, folder `/ (root)`.

1. Push to `main`.
2. **Enable Pages:** repo → Settings → Pages → Source "Deploy from a branch", branch `main`, `/ (root)`.
3. **Verify the domain** (to prevent takeover by other repos): GitHub → organization STACK25 → Settings → Pages → "Add a domain" → `not-yet.app`, create the displayed TXT record in Cloudflare.
4. **Cloudflare DNS** (zone `not-yet.app`), all records **"DNS only" (grey cloud), no proxy**:

   | Type | Name | Content |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | AAAA | `@` | `2606:50c0:8000::153` |
   | AAAA | `@` | `2606:50c0:8001::153` |
   | AAAA | `@` | `2606:50c0:8002::153` |
   | AAAA | `@` | `2606:50c0:8003::153` |
   | CNAME | `www` | `stack25.github.io` |

5. **Custom domain:** repo → Settings → Pages → Custom domain `not-yet.app` (already in `CNAME`). Wait until the DNS check is green and the certificate is issued, then tick **"Enforce HTTPS"**.
6. **Email:** Cloudflare → Email → enable Email Routing (creates MX/TXT itself), rule `info@not-yet.app` → your own mailbox. The MX records do not interfere with Pages.

## Check Universal Links (AASA)

The file (content identical to the old `not-yet-web`) must be served at `https://not-yet.app/.well-known/apple-app-site-association` without a redirect, with HTTP 200 and valid JSON.

```
# Pages, redirects, HTTPS
curl -sI https://not-yet.app/ | head -n 5
curl -sI http://not-yet.app/ | grep -i location          # -> https://not-yet.app/
curl -s -o /dev/null -w "%{http_code}\n" https://not-yet.app/de/privacy/   # 200
curl -s -o /dev/null -w "%{http_code}\n" https://not-yet.app/t/7xk2ab9pqd  # 404, but shows the tag page

# AASA
curl -sI https://not-yet.app/.well-known/apple-app-site-association
curl -s  https://not-yet.app/.well-known/apple-app-site-association | python3 -m json.tool

# What Apple's CDN makes of it (after go-live, can take up to a few hours)
curl -s https://app-site-association.cdn-apple.com/a/v1/not-yet.app
```

The last line must show the JSON with `88856Y29Z8.com.decudo.notyet` and `/t/*`. Then scan an NFC tag on the iPhone (or tap `https://not-yet.app/t/test1234` in Notes): with the app installed, Not Yet opens; otherwise the tag page.

### Plan B: Content-Type of the AASA

GitHub Pages serves the extensionless file as `application/octet-stream`. If Apple's CDN rejects it because of that (empty response or error in the CDN test):

1. In Cloudflare, switch the records for `@` and `www` to "Proxied" (orange cloud), SSL/TLS mode "Full (strict)".
2. Rules → Transform Rules → Modify Response Header: condition URI Path equals `/.well-known/apple-app-site-association`, action Set static `Content-Type: application/json`.
3. `curl -sI …/apple-app-site-association` then shows `content-type: application/json`; repeat the CDN test.
4. Add Cloudflare as a service provider for the website to section 2 of the privacy policy (in all languages, `tools/i18n/*.json`).

## Regenerating images

**Hero:** `assets/img/hero-<alarm|wheel|home|focus|bedtime>-<light|dark>-<300|600>.webp` from the marketing screenshots in the app repo (`docs/status/screens/marketing/`, `iphone-alarm-task`, `-run-wheel`, `-home-morning`, `-focus-running`, `-bedtime-night`; `-paper` = light, `-warmnight` = dark), Pillow, quality 82. The watch images (Watch Runs v3, P97) are real screenshots from the Watch simulator (Series 11, 46 mm, 416 × 496 = full display, nothing cropped): hero `hero-watch-step.webp` (300 px, step with rocket button), "Apple Watch" tile `watch-start.webp` (`home`), `watch-step.webp` (`run-wheel-stamp`, after ~10 s) and `watch-done.webp` (`run-wheel-stamp-press`, after ~4 s), each 416 px. The tile cycles start → step → DONE three times while the watch is visible (`home.js`); with reduced motion it stays on the step. Clock time: `simctl status_bar` does not work on watchOS; for a morning time in the simulator set `launchctl setenv TZ <zone>` (e.g. `Pacific/Fiji` if it is around 7 a.m. there) and `defaults write -g AppleLocale en_US`, restart Carousel (`launchctl stop com.apple.Carousel`), then reset both afterwards (all via `xcrun simctl spawn <Watch> …`). The clock time is no longer retouched. `water-glass.webp` is the pixel glass from `NotYetDesign/Pixel/WaterGlass.swift` (full, 10 × 11 px, 1x; CSS scales it by whole numbers).

The other app screens come from `docs/status/screens/native/` in the app repo (via the style mockups `docs/design/mockups/website-styles/img/s02-*`), as WebP at 720 px and scaled down to 360 px (Pillow, quality 82). Naming scheme `assets/img/<screen>-<light|dark>-<360|720>.webp`. The rotation demo (`ticket`, `tally`, `rocket`, each light + dark) deliberately shows different morning steps and mechanics: `scripts/native/screenshot.sh run-flow <out.png> [--dark] --time 9:41 --arg turned 1 --arg seed 42 --arg steps 6` plus Ticket `--arg gesture ticket --arg mechanic countdown --arg handled 2` (Brush your teeth), Tally `--arg gesture tallyCounter --arg mechanic bossFight --arg handled 4` (Get dressed), Rocket `--arg gesture rocket --arg mechanic diceOrder --arg handled 1` (Take your meds); `--wait 10` so that the boss and dice are fully drawn. New marketing screens (consistent clock times, Run #24) can simply replace the files under the same names. `og.png`/`og-<code>.png` are screenshots of `tools/i18n/og.html` (1200×630, claim and subline per language): `python3 tools/build-i18n.py --og`.
